# Dataset Experiment Specs

This folder stores per-dataset experiment specifications used by this thesis project.

## Naming Convention
- `docs/datasets/<dataset_name>_experiment_spec.md`

## Purpose
Each spec should define:
1. Task framing for this dataset
2. Exact model input contract
3. Expected model output contract
4. Ontology / constraints source
5. Evaluation assumptions and known caveats
